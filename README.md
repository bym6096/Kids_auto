# YouTube Kids 자동 로그인 (Chrome 확장)

크롬에서 YouTube Kids가 로그아웃되면, 로그아웃 후 나오는 화면을 자동으로 따라가서 다시 로그인하는 확장 프로그램입니다.

## 설치 (개발자 모드)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 저장소의 `extension` 폴더 선택
4. 설치되면 설정 페이지가 자동으로 열립니다.
5. 툴바의 확장 아이콘을 누르면 작은 팝업에서 **자동 로그인 사용/안 함**을 바로 켜고 끌 수 있습니다(꺼져 있으면 아이콘에 `OFF` 표시). 상세 설정은 팝업의 "상세 설정 열기"로 엽니다.

## 설정

| 항목 | 설명 |
|---|---|
| 로그인 방식 | **감독 대상 Google 계정으로 로그인**(기본): `보호자입니다 → 또는 …감독 대상 Google 계정으로 로그인 → 로그인`. **보호자 계정으로 시작**: `보호자입니다 → 다음 → 생년 입력 → 안내 영상(텍스트 표시 → 다음) → 보호자 계정으로 로그인 → 로그인` |
| 생년 4자리 (선택) | "보호자 계정" 방식의 연령 확인 화면용. 비우면 그 화면에서 멈추고 직접 입력을 기다립니다. |
| 프로필 이름 (선택) | 프로필 선택 화면에서 누를 프로필 (이 화면은 아직 실제 화면으로 검증하지 못했습니다) |

## 동작 방식

- `www.youtubekids.com`에서 로그아웃 화면의 버튼을 순서대로 클릭합니다. 이미 로그인된 화면에서는 아무것도 하지 않습니다.
- `로그인` 버튼은 구글 로그인 **팝업**을 띄울 수 있습니다. 스크립트 클릭은 크롬이 팝업을 차단하므로, 확장이 `youtubekids.com`에 한해서만 팝업을 허용 설정합니다(`contentSettings` 권한).
- **구글 계정 정보(이메일/비밀번호)는 다루지 않습니다.** `로그인`을 누르면 뜨는 구글 팝업은 확장이 건드리지 않습니다(평소처럼 `로그인`만으로 끝나는 경우를 전제).
- 같은 단계는 일정 시간 안에 정해진 횟수까지만 시도합니다(무한 반복 방지).
- 설정 페이지의 **동작 기록**에서 어느 단계까지 진행됐고 어디서 멈췄는지 볼 수 있습니다.

## 알려진 한계

- 로그아웃 화면의 DOM은 구글이 바꾸면 깨질 수 있습니다. 한국어/영어 문구와 확인된 id를 기준으로 동작합니다.
- 프로필 선택 화면은 실제 계정으로 끝까지 검증하지 못했습니다. 멈추는 곳이 있으면 동작 기록을 알려주세요.
- 로그아웃이 너무 자주 일어난다면 `chrome://settings/cookies`에서 **"Chrome을 닫을 때 쿠키 및 사이트 데이터 삭제"**가 꺼져 있고, `youtubekids.com`/`google.com`이 예외 목록에 없는지 먼저 확인해 보세요. 이 경우 확장보다 설정 수정이 근본 해결입니다.

## 개발

테스트는 Playwright로 확장을 실제 크롬에 로드해서 진행했습니다(실제 youtubekids.com 로그아웃 플로우 + 구글 단계 목 페이지).
